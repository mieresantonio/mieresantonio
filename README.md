## 🚀 Proyecto principal: Block Ethos — Web3 Space

**[Block Ethos](https://github.com/mieresantonio/block-ethos)** — plataforma en español para aprender blockchain haciendo: rutas guiadas, lecciones en Markdown, quizzes con nota real, progreso persistente, gamificación y certificados verificables. Incluye un laboratorio interactivo (SHA-256 en vivo y una cadena de bloques manipulable) y verificación pública de certificados.

[![Demo en vivo](https://img.shields.io/badge/Demo_en_vivo-Block_Ethos-16a34a?style=flat-square)](https://BC123.pythonanywhere.com/)

Nació como proyecto final del bootcamp Full Stack de 4Geeks Academy (Grupo 3) y sigue evolucionando como producto propio. Stack: React + Flask + SQLite, con autenticación JWT.
